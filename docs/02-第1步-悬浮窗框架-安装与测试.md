# 第 1 步：悬浮窗框架（安装与测试说明）

本步交付：工程骨架、悬浮窗（拖动 / 缩放 / 锁定穿透 / 折叠 / 回到最新 / 样式持久化）、前台服务、权限与保活引导页、**媒体会话探针**。弹幕来自“模拟弹幕源”，**还不连 B 站**。

> 我这边的环境连不上 Google/Maven 仓库，**没法编译**。代码已做过 Kotlin 语法检查、纯 Kotlin 部分的单元测试已通过，但 Android 相关代码只能靠你那边编译验证。第一次编译如果报错，把 Android Studio 底部 **Build** 窗口里的红色报错整段复制给我。

## 一、安装 Android Studio 并运行（Windows）

1. 下载：<https://developer.android.com/studio>，安装时全部默认即可。
2. 第一次启动选 **Standard** 安装方式，它会自动下载 Android SDK（几个 GB，需要一点时间）。
3. 打开工程：**File → Open**，选择文件夹
   `C:\Users\white\Desktop\Anime\learn\program\Danmaku Android`（里面有 `settings.gradle.kts` 的那一层）。
4. 等右下角的 **Gradle Sync** 跑完。第一次会下载 Gradle 8.14.3 和依赖库，可能 5～20 分钟。
   - 弹出“建议升级 Android Gradle Plugin”：**先不要升级**（点关闭或 “Don't ask for this project”）。我选的是确认存在、互相兼容的稳定版本，等功能跑通再统一升级。
   - 如果报 JDK 相关错误（例如 `Unsupported class file major version`）：**File → Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK**，选 17 或 21（没有就在下拉框里点 *Download JDK*）。
   - 如果依赖下载失败/超时：多半是网络连不上 Google 的 Maven 仓库，告诉我，我改成国内镜像。
5. 手机开启 USB 调试：设置 → 关于手机 → 连续点“版本号”7 次打开开发者选项 → 开发者选项里打开 **USB 调试**。
   小米/HyperOS 还需要打开 **“USB 安装”** 和 **“USB 调试（安全设置）”**（需要插 SIM 卡并登录小米账号，这是小米的限制）。
6. 用数据线连电脑，手机上点“允许调试”，Android Studio 顶部设备下拉框选中你的手机，点绿色 ▶ **Run**。

不想连线也可以：**Build → Build App Bundle(s) / APK(s) → Build APK(s)**，生成的
`app\build\outputs\apk\debug\app-debug.apk` 传到手机安装。
（用 APK 文件安装时，Android 13+ 在开启“通知使用权”时可能提示“受限制的设置”，处理方法见探针页面。）

## 三、本步的已知限制

- **锁定时窗口会略变淡**：Android 12+ 规定触摸穿透的悬浮窗整体不透明度不能超过 80%，否则下层 App 收不到触摸。这是系统限制，绕不过去。
- **被系统杀掉后不会自动恢复**（服务用的是 `START_NOT_STICKY`）。第 2 步接入直播后再决定是否要“被杀后自动重连”。
- 窗口位置按像素保存，横竖屏切换后会被推回屏幕内，可能不在原来的位置。
- 国产 ROM 保活引导页的菜单名称是“大致位置”，我没有逐个机型核实；你用什么手机告诉我，我按实机调整。
- 依赖库版本是 2024 年底的稳定版，偏旧但稳。Android Studio 提示升级时可以先忽略。

## 四、代码结构（本步）

```
app/src/main/java/com/civinb/danmuji/
├─ DanmuApp.kt                  Application：设置仓库、通知渠道
├─ model/DanmakuItem.kt         统一弹幕模型（直播/视频共用）
├─ source/                      弹幕来源接口 + 模拟源（第 2 步在这里加直播源）
├─ settings/                    悬浮窗设置（DataStore 持久化）
├─ overlay/
│  ├─ FloatingWindowController  三个悬浮窗口：主面板 / 折叠小球 / 解锁按钮
│  ├─ DanmakuAdapter            RecyclerView 适配器（只追加 + 头部裁剪）
│  └─ DanmakuBuffer             后台线程写入、UI 每 150ms 批量取出
├─ service/OverlayService.kt    前台服务（specialUse），持有悬浮窗和弹幕来源
├─ probe/                       媒体会话探针
├─ ui/                          Compose 界面：首页 / 样式 / 权限保活 / 探针
└─ util/Permissions.kt          权限检查与跳转系统设置
```

性能相关的做法：弹幕先进缓冲区，UI 每 150ms 批量刷新一次；列表关闭了条目动画；超过“最多保留条数”从头部删除（向上翻看时放宽到 3 倍，避免正在看的内容被删）。
