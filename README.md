# 弹幕机（Android）

以悬浮窗列表形式显示 B 站直播 / 视频弹幕，配合 B 站官方 App 使用。仅供个人使用。

当前版本 1.1.0，已实机测试通过的功能：

- 直播弹幕（醒目留言 / 礼物 / 进场开关、隐藏直播间表情、断线重连、网络切换恢复）
- 视频弹幕（分P选择、自动 / 手动进度同步、多P自动切换）
- 悬浮窗（拖动、缩放、锁定穿透、折叠、回到最新、样式持久化）
- 过滤（关键词、正则、用户、仅显示、合并重复 ×N）
- 可选扫码登录（凭证本地加密、可退出）
