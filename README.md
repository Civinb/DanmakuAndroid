# Bilibili弹幕机（Android）

简体中文 | [English](README_en.md)

本弹幕机可以用于视频内容不那么重要但是又想去看看弹幕反应的场合，
以悬浮窗列表的形式显示 B 站直播 / 视频弹幕，配合 B 站官方 App 使用。


## 功能

- **直播弹幕**：醒目留言、礼物、进场可开关；隐藏直播间表情；断线自动重连
- **视频弹幕**：自动跟随 B 站播放进度，也可手动控制；B 站里切换分P时自动切换弹幕
- **悬浮窗**：拖动、缩放、锁定穿透、折叠、回到最新、样式可调；横竖屏分别记住位置和大小；黑屏背景（点黑色区域弹出播放控制）
- **过滤**：关键词、正则、用户屏蔽；仅显示模式；合并重复弹幕
- **其他**：可选扫码登录（过期时会提醒）、应用内检查更新、中文 / English 界面
- **注意**：观看视频弹幕时只有登录后才能显示完整弹幕，未登录弹幕量只有约10%-20%

## 使用

1. 从 [Releases](https://github.com/Civinb/DanmakuAndroid/releases) 下载安装，授予悬浮窗权限
2. 首页输入直播间号、BV 号或链接 → 开始，自动判断是直播还是视频
3. 看视频时在 B 站 App 里播放同一个视频即可同步（自动同步需要开启“通知使用权”）
4. 推荐：在 B 站直播间或视频页点击 分享 → 更多 → 弹幕机，直接启动
