# 弹幕机（Android）

以悬浮窗列表的形式显示 B 站直播 / 视频弹幕，配合 B 站官方 App 使用：一边在 B 站 App 里看，一边在悬浮窗里逐条看弹幕。

当前版本：**1.2.0**　·　系统要求：**Android 8.0 及以上**

## 功能

**直播弹幕**
- 输入直播间号、直播间链接或分享文字即可连接；也可以在 B 站 App 直播间点“分享”，直接选择“弹幕机”启动
- 醒目留言、礼物、进场消息可分别开关；可隐藏直播间表情
- 断线自动重连，切换 Wi-Fi / 流量后自动恢复

**视频弹幕**
- 输入 BV 号或视频链接，支持多P视频选择分P
- 自动同步：跟随 B 站 App 的播放进度（播放、暂停、拖动、倍速），可用 ±1 / ±5 秒微调偏移
- 手动同步：自己控制播放、暂停和进度
- 在 B 站 App 里切换分P时自动切换对应弹幕

**悬浮窗**
- 拖动标题栏移动，拖动右下角调整大小
- 锁定：触摸穿透到下面的 App
- 折叠成小球；向上翻看历史时可一键“回到最新”
- 黑屏背景：用纯黑盖住下面的画面，只留悬浮窗；点一下黑色区域弹出播放 / 暂停、±10 秒、退出黑屏
- 透明度、字号、行距、颜色等样式可调，位置和样式自动保存

**过滤**
- 按关键词、正则表达式、用户屏蔽；在悬浮窗里长按一条弹幕即可屏蔽该用户或这句话
- “仅显示”模式：只显示命中规则的弹幕
- 合并重复弹幕，显示为 ×N

**其他**
- 可选 B 站扫码登录（登录后弹幕更完整、直播昵称不再打码）
- 应用内检查更新（来自本仓库的 GitHub Releases）
- 支持预见式返回手势

## 安装

1. 到 [Releases](https://github.com/Civinb/DanmakuAndroid/releases) 下载最新的 `.apk`
2. 在手机上安装（需要允许“安装未知应用”）

之后有新版本时，应用会在打开时提示，也可以在“帮助与关于 → 关于与更新”里手动检查。

## 首次使用

| 权限 | 用途 | 是否必需 |
|---|---|---|
| 悬浮窗（显示在其他应用上层） | 显示弹幕窗口 | 必需 |
| 通知（Android 13+） | 常驻通知里的锁定 / 折叠 / 停止按钮 | 建议 |
| 通知使用权 | 读取 B 站的播放进度（视频自动同步），以及黑屏时的播放控制。不读取任何通知内容 | 用视频自动同步时需要 |
| 安装未知应用 | 应用内更新时安装新版本 | 更新时需要 |

- Android 13 及以上，如果“通知使用权”开关是灰色并提示“受限制的设置”：到 应用信息 → 右上角 ⋮ → “允许受限制的设置”，再回来开启。
- 国产系统容易杀后台，请按“帮助与关于 → 权限与后台保活”里的提示设置自启动、电池优化等。

## 使用

1. **看直播**：首页“直播弹幕”输入房间号或链接 → 连接。
2. **看视频**：首页“视频弹幕”输入 BV 号或链接 → 加载 → 选分P → 开始，然后在 B 站 App 里播放同一个视频。
3. 悬浮窗标题栏的按钮依次是：黑屏背景、锁定、折叠、关闭。

更多设置在首页的两个入口里：

- **设置**：悬浮窗样式、过滤规则、B 站账号
- **帮助与关于**：权限与后台保活、连接日志、关于与更新

## 已知限制

- 视频弹幕拿到的是 B 站当前弹幕池里的弹幕。弹幕池有上限，所以弹幕数很多的视频拿不到页面上显示的累计数量；未登录时部分视频只返回部分弹幕。
- 未登录时，B 站会把直播弹幕的用户昵称打码，按用户屏蔽也就不精确。
- 锁定（触摸穿透）时，悬浮窗最多只能 80% 不透明；黑屏背景为纯黑，所以黑屏时点不到下面的 B 站 App。这两点都是 Android 12 起的系统规定。
- 视频自动同步和黑屏播放控制都依赖 B 站 App 向系统公开的媒体会话；如果 B 站 App 改变行为，可能需要改用手动同步。
- 高级弹幕、代码弹幕、BAS 弹幕不显示；没有官方播放器的“智能屏蔽”。

## 隐私

- 不在应用内输入 B 站账号密码，只支持扫码登录。
- 登录凭证用系统密钥库（Android Keystore）加密，只保存在本机；退出登录会同时注销会话并删除本地凭证。
- 应用只访问 B 站接口（获取弹幕）和 GitHub（检查更新），不收集、不上传任何其他数据。

## 从源码构建

- Android Studio（自带 JDK 17 或 21 即可）
- 打开工程根目录，等待 Gradle 同步完成后运行，或 **Build → Generate Signed App Bundle or APK** 生成签名安装包
- 主要依赖：Kotlin、Jetpack Compose、OkHttp、Google brotli 解码器、ZXing
